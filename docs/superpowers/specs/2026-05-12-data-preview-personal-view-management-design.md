# 数据预览个人视图管理设计

## 背景

数据预览模块已经确定为专业 Data Editor 形态，重点参考 DataGrip、DBeaver 和云厂商 DMS 的数据表查看体验。当前原型已经具备数据源 / 数据库 / 表选择、对象树、数据网格、列设置、筛选、排序、关联和复制 SQL 等基础交互。

下一步产品打磨选择聚焦“视图管理”，目标是让用户保存自己常用的看表方式，减少重复调整列、筛选和排序的成本。

## 设计目标

- 支持用户为当前表保存个人视图。
- 视图入口轻量，不做复杂管理后台。
- 视图只保存“看表方式”，不保存查询结果。
- 切换视图时能恢复列、筛选、排序和分页大小。
- 未保存修改必须明确提示，避免用户误切换导致配置丢失。

## 非目标

本期不做：

- 团队共享视图。
- 视图权限管理。
- 跨表复用视图。
- 保存查询结果快照。
- 导出偏好保存。
- 单元格显示偏好保存。
- 关联配置保存。

## 页面入口

采用“轻量视图下拉”方案。

入口放在表标签栏下方、表操作工具条左侧：

```text
[ajxx_tab 案件信息表 · ds_demo]

视图：默认视图 ▼   列设置  筛选  排序  关联  复制SQL   50条/页
```

这样视图与当前表强绑定，不占用左侧对象树，也不会干扰数据源、数据库和表选择。

## 下拉菜单结构

```text
视图：默认视图 ▼

我的视图
✓ 默认视图
  同步结果排查
  只看有效案件
  最近30天创建

────────
保存当前视图
另存为新视图
重命名当前视图
删除当前视图
```

规则：

- 默认视图始终存在。
- 默认视图不能删除。
- 默认视图不能重命名。
- 普通个人视图可以重命名和删除。
- 视图名称过长时在下拉中省略显示。
- 当前选中视图使用勾选状态展示。

## 保存内容

个人视图保存以下配置：

- 字段显隐。
- 字段顺序。
- 列宽。
- WHERE 筛选条件。
- ORDER BY 排序条件。
- 分页大小。

个人视图不保存：

- 当前页码。
- 当前查询结果。
- 单元格选中状态。
- 导出配置。
- 关联配置。
- 当前数据源 / 数据库 / 表。

视图归属于当前表。`ajxx_tab` 的视图只在 `ajxx_tab` 下出现，不跨表复用。

## 视图状态

未修改时：

```text
视图：默认视图
```

修改列显隐、列顺序、列宽、筛选、排序或分页大小后：

```text
视图：默认视图 *
```

星号表示当前视图有未保存修改。

保存成功后星号消失。

## 视图操作流程

### 切换视图

如果当前没有未保存修改，点击视图后立即切换。

如果当前有未保存修改，切换前弹出确认：

```text
当前视图有未保存修改。
切换到“同步结果排查”会放弃当前修改。

[取消] [放弃修改并切换]
```

确认后恢复目标视图保存的列、筛选、排序和分页大小。

### 保存当前视图

- 当前是普通个人视图时，直接覆盖保存。
- 当前是默认视图时，允许覆盖个人默认配置，但不删除系统默认能力。
- 保存成功后未保存标记消失。
- 保存失败时保留未保存标记。

### 另存为新视图

点击“另存为新视图”后弹轻量输入框：

```text
视图名称
[最近30天有效案件        ]

[取消] [保存]
```

校验规则：

- 名称不能为空。
- 同一张表下不能与已有个人视图重名。
- 名称最长 30 个中文字符。
- 保存成功后自动切换到新视图。

### 重命名当前视图

- 默认视图不允许重命名。
- 普通个人视图可重命名。
- 空名和重名必须拦截。

### 删除当前视图

- 默认视图不允许删除。
- 删除普通个人视图前二次确认。
- 删除成功后自动切回默认视图。
- 删除失败时保留当前视图。

## 前端状态模型

```ts
type DataPreviewView = {
  id: number | string
  name: string
  tableKey: string
  isDefault: boolean
  config: {
    columns: Array<{
      key: string
      visible: boolean
      width?: number
      order: number
    }>
    filters: Array<{
      field: string
      operator: string
      value: string | number | boolean | null
    }>
    sorts: Array<{
      field: string
      direction: 'ASC' | 'DESC'
      order: number
    }>
    pageSize: number
  }
}
```

`tableKey` 建议组合为：

```text
datasourceId + database + schema + table
```

这样同名表在不同库中不会冲突。

## 接口草案

```text
GET    /data-preview/views?datasourceId=&database=&schema=&table=
POST   /data-preview/views
PUT    /data-preview/views/{viewId}
PATCH  /data-preview/views/{viewId}/rename
DELETE /data-preview/views/{viewId}
```

接口只保存配置 JSON，不保存查询结果。

## 异常处理

- 视图列表加载失败：页面仍可使用默认视图，视图下拉显示“视图加载失败 / 重试”。
- 保存失败：保留当前未保存状态，星号不消失。
- 删除失败：保留当前视图，不切回默认。
- 字段不存在：恢复视图时跳过缺失字段，并提示“部分字段已不存在”。
- 筛选字段不存在：该筛选条件标红，用户可删除或重置视图。
- 排序字段不存在：自动移除该排序，并提示。
- 当前表无个人视图：只展示默认视图。

## 验收标准

- 表工具条左侧出现 `视图：默认视图 ▼`。
- 下拉中能看到当前表的个人视图列表。
- 能切换视图。
- 能保存当前视图。
- 能另存为新视图。
- 能重命名普通个人视图。
- 能删除普通个人视图。
- 默认视图不能删除、不能重命名。
- 修改列显隐、列顺序、列宽、筛选、排序、分页大小后，当前视图显示未保存状态 `*`。
- 未保存状态下切换视图会二次确认。
- 恢复视图后，数据网格、WHERE、ORDER BY、分页大小同步更新。

## 测试用例

### P0

- 打开数据预览页面，默认显示 `视图：默认视图`。
- 修改列显隐后出现 `*`。
- 点击保存当前视图后 `*` 消失。
- 另存为新视图成功，并自动切换到新视图。
- 切换视图后列显隐、筛选、排序恢复正确。
- 未保存状态下切换视图出现确认弹窗。
- 删除普通个人视图后自动回到默认视图。

### P1

- 重命名视图成功。
- 重名保存被拦截。
- 空名称保存被拦截。
- 默认视图不能删除。
- 默认视图不能重命名。
- 视图列表加载失败时页面仍可查数。
- 字段不存在时恢复视图有明确提示。

### P2

- 视图数量较多时下拉可滚动。
- 视图名称过长时省略显示。
- 切换数据源 / 数据库 / 表后，视图列表跟随当前表变化。
- 刷新页面后能恢复默认视图配置。
