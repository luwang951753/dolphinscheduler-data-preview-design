# 字段映射设计

## 目标

让用户从源表字段中自由选择需要同步的字段，并设计目标表字段。字段映射区要清楚展示源字段和目标字段之间的对应关系。

## 源字段区

源字段必须展示：

- 字段名
- 源字段类型
- 字段注释
- 是否主键
- 是否允许为空

交互必须支持：

- 全选字段
- 反选字段
- 清空选择
- 只勾选部分字段

## 目标字段设计区

目标字段必须支持：

- 字段名可编辑
- 目标类型可选择
- 字段注释可编辑
- 主键可设置
- 可空可设置

目标字段的默认类型应根据目标库类型自动推荐，例如 MySQL 到 PostgreSQL 时要做类型映射。

## 连线映射

字段映射可以通过拖拽连线表达：

- 左侧源字段有连接点。
- 右侧目标字段有连接点。
- 用户可以从左侧源字段连接点拖到右侧目标字段。
- 用户也可以从右侧目标字段连接点反向拖回左侧源字段。
- 不应只允许拖到很小的圆点，字段头部区域也应可作为有效落点。
- 连线即使发生交叉，也必须保持可见，不能被左右字段面板遮挡。
- 映射关系调整后，配置生成和 DDL 生成必须使用最新映射。

## 历史问题

- 源字段无法勾选。
- 源字段类型显示为 `unknown`。
- 第 2 步虽然有全选/反选，但无法只勾选部分字段。
- 目标字段区曾出现不必要的全选、全不选、反选按钮。
- 拖拽连线后曾出现 `id` 和 `ajbh` 对应关系互换，需要重点回归。
