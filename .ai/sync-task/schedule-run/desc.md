# 执行与调度

## 执行方式

同步任务需要支持：

- 立即执行
- 周期调度

曾经加入过“手动业务时间”，用户要求删除后恢复立即执行。

## 立即执行

立即执行不能只是创建一个下线工作流。正确链路应为：

1. 保存 DolphinScheduler 工作流定义。
2. 上线工作流定义。
3. 调用启动工作流实例接口。
4. 页面提示同步实例已启动。
5. 跳转到运行实例详情，或在当前页展示运行进度。

## 周期调度

周期调度应复用 DolphinScheduler 原有“工作流定义 -> 工作流列表右侧 -> 定时”的弹框交互风格。

要求：

- 不破坏原有工作流定时功能。
- 不强制要求同步任务前面所有步骤都配置完成才能打开周期调度。
- 交互应友好展示分、时、日、月、周等配置，不要求用户直接手写复杂表达式。

## 历史问题

- 进入同步任务页面时报过 `NumberFormatException: For input string: "NaN"`。
- 周期调度曾限制过多。
- Dolphin 原有工作流定时曾疑似被改坏，后续必须优先回归原生功能。
