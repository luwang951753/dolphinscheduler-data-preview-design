# 数据预览模块测试用例基线文档

## 1. 文档定位

本文档用于定义“数据预览”模块每次开发后必须执行的测试范围与测试用例，作为后续真实点击自测和回归测试的基线。

目标是让后续每次做数据预览开发时，都清楚知道：

- 哪些流程必须测
- 哪些基础能力必须回归
- 哪些异常必须覆盖
- 哪些原生功能必须保护

## 2. 测试总体原则

### 2.1 核心原则

- 必须采用模拟人类逐步点击页面方式测试
- 不能只跑接口
- 不能只跑构建
- 不能只验证单一 Happy Path
- 结果必须可记录、可复现

### 2.2 测试分层

每次交付前，至少分四层执行：

1. 页面主流程测试
2. 基础能力测试
3. 异常与边界测试
4. 原生功能保护测试

## 3. 测试环境基线

### 3.1 页面地址

- DolphinScheduler UI：`http://127.0.0.1:12345/dolphinscheduler/ui`
- 数据预览页面：建议为 `/ui/data-preview`

### 3.2 测试账号

- 用户名：`admin`
- 密码：`dolphinscheduler123`

### 3.3 典型数据源

建议至少准备：

- `mysql_case_workbench`
- `pgsql_test1`

### 3.4 典型测试表

建议至少准备：

- 单表数据查看用表
- 可关联的主表
- 可关联的明细表

后续正式开发时，应在本文件中补充明确的表名和字段名。

## 4. 用例分级

### 4.1 P0

阻塞交付用例，失败则不能交付。

### 4.2 P1

关键能力用例，重要改动后必须执行。

### 4.3 P2

体验和边界增强用例，可按改动范围补测。

## 5. P0 主流程用例

### TC-P0-001 页面可进入

#### 目标

验证数据预览页面可以正常进入。

#### 操作步骤

1. 登录系统
2. 点击“数据预览”导航

#### 预期结果

- 成功进入页面
- 页面结构完整
- 无报错、无白屏

### TC-P0-002 选择数据源、数据库、主表后可看到数据

#### 目标

验证最基础查数流程可用。

#### 操作步骤

1. 选择数据源
2. 选择数据库
3. 选择主表
4. 检查主表注释是否展示
5. 点击“查询”

#### 预期结果

- 字段列表正确加载
- 主表注释可见
- 点击“查询”后结果表出现
- 默认返回分页数据

### TC-P0-003 字段定制化可用

#### 目标

验证字段显隐和字段顺序调整可用。

#### 操作步骤

1. 只勾选部分字段
2. 隐藏一个字段
3. 调整字段顺序
4. 点击“反选字段”

#### 预期结果

- 结果表字段随之变化
- 顺序调整立即生效
- 没选中的字段不展示
- 字段默认是全选状态
- 字段面板应主要展示字段名称和注释，而不是突出字段类型
- 字段名称应明显加粗
- 字段注释应使用更小的辅助文字
- 全选、反选、清空应作为轻量操作栏存在，而不是突兀的大按钮堆叠

### TC-P0-004 简单筛选可用

#### 目标

验证基础筛选能力可用。

#### 操作步骤

1. 使用顶部或结果区快捷筛选
2. 新增文本字段筛选
3. 新增数值字段筛选或时间字段筛选
4. 点击“查询”

#### 预期结果

- 结果正确过滤
- 已生效条件清晰可见
- 可删除单个条件
- 高频筛选入口位置应靠近结果区，而不是藏在过重的左侧面板里

### TC-P0-004A 表头筛选图标可用

#### 目标

验证字段右侧的筛选 / 搜索图标不是装饰图标，而是可点击筛选入口。

#### 操作步骤

1. 打开数据预览页面
2. 点击 `case_no` 表头右侧的筛选 / 搜索图标
3. 在筛选浮层中输入 `AJ-202605`
4. 点击 `应用筛选`
5. 再点击 `case_no` 表头右侧已高亮的筛选 / 搜索图标

#### 预期结果

- 第 2 步后打开筛选浮层
- 字段默认选中 `case_no`
- 应用后 WHERE 条新增 `case_no` 条件
- 第 5 步再次点击时进入该字段已有筛选条件的编辑状态

### TC-P0-005 排序可用

#### 目标

验证结果表头排序可用。

#### 操作步骤

1. 点击结果表头排序
2. 再切换为反向排序

#### 预期结果

- 升序可用
- 降序可用
- 排序字段有清晰标识

### TC-P0-006 简单关联查询可用

#### 目标

验证主表与关联表联合查看能力可用。

#### 操作步骤

1. 选择主表
2. 新增关联表
3. 配置关联字段
4. 选择左连接或内连接
5. 展示关联表字段

#### 预期结果

- 关联配置成功
- 结果表出现关联字段
- 数据结果正确返回
- 左侧关联面板中的配置方式应简单直观，不做复杂 SQL Builder 体验

### TC-P0-007 分页可用

#### 目标

验证结果分页能力可用。

#### 操作步骤

1. 切换下一页
2. 修改每页条数
3. 返回上一页

#### 预期结果

- 分页切换正常
- 每页条数切换正常
- 结果表刷新正常

### TC-P0-008 导出可用

#### 目标

验证当前查询结果可导出。

#### 操作步骤

1. 配置字段、筛选、排序
2. 点击导出

#### 预期结果

- 成功导出当前结果
- 导出内容与当前筛选结果一致

## 6. P1 重要能力用例

### TC-P1-001 多条件筛选可叠加

#### 目标

验证多个筛选条件组合可用。

#### 预期结果

- 多条件 AND 生效
- 条件列表清晰

### TC-P1-002 结果表单元格快捷操作可用

#### 目标

验证从单元格快速发起操作。

#### 操作步骤

1. 对某单元格执行“仅看此值”
2. 对某单元格执行“排除此值”
3. 对某单元格执行“复制”

#### 预期结果

- 能快速生成筛选
- 复制值成功

### TC-P1-003 自定义字段可创建

#### 目标

验证轻量自定义字段可用。

#### 操作步骤

1. 新增自定义字段
2. 使用文本拼接或数值计算
3. 保存

#### 预期结果

- 自定义字段出现在字段列表中
- 结果表可正常显示

### TC-P1-004 保存视图可用

#### 目标

验证用户可复用常见查数配置。

#### 操作步骤

1. 配置字段、筛选、排序
2. 点击保存视图
3. 重新打开该视图

#### 预期结果

- 保存成功
- 打开后配置正确恢复

## 11. 每次开发后的最小回归集

后续数据预览每次开发完成后，至少执行：

1. TC-P0-001
2. TC-P0-002
3. TC-P0-003
4. TC-P0-004
5. TC-P0-005
6. TC-P0-006
7. TC-P0-007
8. TC-REG-001

如果改动涉及自定义字段、保存视图、导出、权限、错误处理，则必须追加对应 P1 / 异常用例。

## 12. 交付时必须说明的测试结论

每次交付时必须明确反馈：

- 实际执行了哪些用例编号
- 哪些用例通过
- 哪些用例未执行及原因
- 是否执行了原生功能保护测试
- 是否发现并修复问题

## 13. 后续维护建议

后续每新增一个功能点，都应同步补一条测试用例。

原则是：

- 功能需求文档定义“要做什么”
- 页面原型文档定义“怎么用”
- 测试用例文档定义“怎么验”

三者必须一起维护，后续开发才会稳定。
